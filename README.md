# Anirudh Portfolio - Flutter Exam Project

## Run in VS Code

1. Install Flutter SDK and the Flutter extension in VS Code.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:
   flutter pub get
5. Start an emulator or connect a phone.
6. Run:
   flutter run

For Chrome/web:
   flutter run -d chrome

## Pages
- Home Page
- About Me Page
- My Projects Page

## Exam requirements covered
- Responsive design using LayoutBuilder, Wrap and SingleChildScrollView.
- Navigation between all pages using named routes.
- Photo/avatar area using a Flutter CircleAvatar.
- Skills and areas of expertise.
- Project cards.
- Back buttons and home navigation.
